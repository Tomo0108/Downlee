# Downlee UI ガイドライン

Rakuform の `docs/ui-guidelines.md`（RakuManual の作法）に合わせる。ここには Downlee で決めたことだけを書く。

## 1. 画面の情報は最小限、説明はヘルプへ

- 画面に常時出すのは「何か」が分かる最小限の言葉（見出し・ラベル・状態・エラー）。「なぜ・どう動くか」は見出しの右の ? ボタン（`HelpButton`）に入れる。
- 設定は `SettingRow` の `hint` に書けば、自動でヘルプボタンになる。`<p>` で説明を書かない。
- ヘルプの中身は 1 項目 1〜2 文の箇条書き。
- 画面に出したままにするもの：状態（進み具合・完了・失敗）、エラーとその次の一手、空の状態の次の一手、DRM でダウンロードできないことの一文。

## 2. 言葉

- 敬体。ボタンは動詞（「読み込む」「保存」「変換」）、ラベルは名詞。ボタン名は［ ］、画面上の名前は「 」で囲む。
- 内部名（yt-dlp の引数・形式 ID など）は［詳細］か［上級者向け］の中だけに出す。

## 3. 色

- 主軸の色はアイコンの紫〜青（`data-accent="violet"`、`src/index.css`）。進捗バーはアイコンと同じグラデーション（`.brand-gradient`）。
- 状態の色は `--semantic-*`（完了＝success、注意＝warning、失敗＝destructive）。色だけで伝えず、文字かアイコンを添える。
- ダーク表示に対応する。色はトークンで書く。

## 4. 構成

| 場所 | 置くもの |
| --- | --- |
| サイドバー | ロゴと名前・折りたたみ（Ctrl+B）、［見つける］［ダウンロード］［変換］［履歴］（Ctrl+1〜4）。起動時は［見つける］、下に［設定］（Ctrl+,） |
| ダウンロード | URL 欄・形式・［読み込む］、読み込んだ動画（形式・画質・［詳細］）、一覧 |
| 見つける | アドレス欄・［開く］、専用ブラウザの操作、見つかったメディア |
| 変換 | ファイルを落とす場所、変換先の形式、区間、一覧 |
| 履歴 | 検索、一覧（再生・フォルダ・もう一度・URL のコピー・消す） |
| 設定 | 保存・既定・字幕・仕上げ・速さ・ログイン・通知・ツール・表示・上級者向け |

## 新機能のチェックリスト

- [ ] 説明文を画面に直接書いていない（ヘルプに入れた）
- [ ] ライト・ダークの両方で読める
- [ ] 失敗したときに、利用者の言葉で次の一手が分かる
- [ ] DRM を回避する処理を入れていない
