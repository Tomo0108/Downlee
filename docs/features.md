# Downlee の機能と Video DownloadHelper（プレミアム）との対応

Video DownloadHelper（以下 VDH）はブラウザの拡張機能、Downlee はデスクトップアプリなので、同じことを別の方法で実現しているところがあります。

| VDH（プレミアムを含む） | Downlee | 場所 |
|---|---|---|
| ページで再生される動画の検出 | 専用ブラウザで開いたページが読み込む動画・音声（MP4・WebM・HLS・DASH など）を検出 | 見つける |
| HLS・DASH のダウンロード（待ち時間・回数の制限なし） | 制限なし。分割ダウンロードで高速化 | ダウンロード・見つける |
| 最高画質での保存 | 既定で最高画質（8K・4K・HDR・60fps を含む）。画質の上限・コーデック・形式 ID も指定可 | ダウンロード［詳細］ |
| 映像と音声の結合（アグリゲーション） | 自動（ffmpeg） | — |
| 変換（回数無制限） | ダウンロード時の形式指定（動画 5 種・音声 8 種・GIF）と、手元のファイルの変換（13 形式） | ダウンロード・変換 |
| 1,000 以上のサイト対応 | yt-dlp の対応サイト（1,800 以上） | — |
| ログインが必要なサイト | 専用ブラウザでログイン、または普段のブラウザのログイン情報を使う | 見つける・設定 |
| スマートネーミング（ファイル名の付け方） | ファイル名のひな形（タイトル・投稿者・日付など、フォルダ分けも可） | 設定 |
| 同時ダウンロード数 | 1〜8 | 設定 |
| ダウンロードの履歴 | 履歴（検索・再生・もう一度ダウンロード） | 履歴 |
| ブラックリスト（除外するサイト） | 除外するサイト・広告ブロック（EasyList 系、動画広告を一覧に出さない） | 設定 |
| — | 専用ブラウザへの拡張機能の追加（展開済みフォルダ） | 設定 |
| クイックダウンロード | 「貼ったらすぐ保存」・コピーした URL の通知・URL の一括貼り付け | ダウンロード・設定 |
| 字幕のダウンロード | 字幕の保存（言語の指定・自動生成・埋め込み） | 設定 |
| プロキシ | プロキシ・速度の上限 | 設定 |

VDH にない機能：プレイリスト・チャンネルの一括保存、区間の切り出し、チャプター・サムネイル・メタデータの埋め込み、スポンサー区間の除去、一時停止と再開（アプリを閉じても次の起動で再開）、完了通知、タスクバーの進捗。

## 対応しないもの

- DRM（Widevine・PlayReady・FairPlay）で保護された動画（Netflix・Amazon Prime Video・Disney+・有料の配信サービスなど）。VDH も DRM の解除はしないため、VDH プレミアムの機能で除いたものはありません。
- 画面・タブの録画は入れていません（DRM の動画を録画で保存する用途になりやすいため）。
